訊息整理與教學教材建置心法

從主題設定、資料蒐集到 Canvas 深化編輯，一套可重複使用的教材產出流程。

① 精準資料搜尋

主題明確 格式：文字 / Markdown / PDF / PPT / 影片 語言：中 / 英 來源：社群、新聞、YouTube、期刊 年份：2025 排除廣告宣傳
用 NotebookLM 基本搜尋： 「關於【你的主題】有沒有值得引用的 文章、部落格或新聞，可以化為我在 課堂上的教材」

② 多媒體檔案摘要

  • 利用 NotebookLM 初步搜尋主題資料
  • 對 YouTube 影片 進行重點摘要
  • 適用範疇：新聞影片、教學影片、記錄片、宣導短片、形象影片、TED 影片
「請摘要這則【你的主題】影片的重點」

  • 心智圖整理：「請幫我用心智圖結構整理資料來源，用 Markdown 格式顯示，h1 是題目、h2 是標題，內容整理成條列式」

  • 文案撰寫小幫手：扮演思維縝密的寫作者，從資料中提煉最反直覺、最具影響力的要點，整理成引人入勝的清單文章，附引用連結與發人深省的結尾

CASE STUDY

專題實戰：辨識 AI 詐騙與深偽（Deepfake）

從一則主題出發，用 Canvas 一路產出報導、教材、簡報、語音摘要與互動網頁 —— 完整的六步驟成品產出流程。

01Canvas 啟動

就蒐集到的所有資訊，撰寫一篇深入討論 1500 字的報導文章，語氣幽默輕鬆、標題吸引人；文末整理引用資料並附上連結。

02建立網頁、資訊圖表

整合 Google Sites，將文章轉化為可瀏覽的網頁與資訊圖表。

03建立學習卡、測驗

切回 Canvas 文章，整理重要知識關鍵字，建立 5 張 Canvas「學習卡」與 5 題「測驗」。

04語音摘要

將文章轉化為高質感語音摘要，支援情境化行動學習。

05建立簡報

一鍵將文章重點自動構建為完整簡報。

06開發程式（Vibe Coding）

使用 Tailwind CSS 與原生 JavaScript 製作單頁 RWD 響應式網頁：內建 5 個詐騙故事（如假檢警、投資詐騙）， 每則含 5 段文字與意境圖；頂部下拉選單即時切換卡片內容；Grid 版面顯示圓角陰影卡片（不使用彈出視窗）； 右上角播放鈕以幻燈片方式輪播故事，並搭配平滑淡入淡出動畫，整體 UI 簡約現代。

BONUS TOOLS

外部 Markdown 轉化工具

除了 Canvas 本身，這兩個能與 Markdown 格式搭配的視覺化工具，讓產出更進一步。

M↓

mdPPT — MD 簡報生成器

生成 Markdown 文件 → 調整文件（在 h2 前加上水平線分頁）→ 匯入 mdPPT，即可編輯、設定樣版、播放 / 預覽（Esc），並下載成簡報。

↗ edreamer.github.io/mdppt
✳

Markmap — 心智圖生成器

請 Gemini 以「心智圖結構」輸出 Markdown 格式後，貼入 Markmap 網站即可自動生成互動式心智圖，支援下載為 SVG 圖片或互動式網頁檔案。

↗ markmap.js.org
