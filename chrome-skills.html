第一章 / 認識 Chrome Skills

什麼是 Chrome Skills？

Chrome Skills 是內建於 Chrome 側邊欄「問問 Gemini」中的技能模組，讓 AI 不只回答問題，而是能理解情境、串連多個分頁，直接把任務做完。這代表 AI 從聊天機器人，正式進化成能執行工作的助手。

01 · 技能化

Skills

把常做的任務包裝成可重複使用的指令模組，不用每次重新描述需求。

02 · 情境理解

跨分頁操作

Gemini 能同時讀取多個分頁的內容，進行比對、彙整與交叉分析。

03 · 深度整合

Gemini 深度整合

與 Google 帳號、Workspace 服務串接，減少在應用程式之間來回切換。

適合情境：資料研究、內容撰寫、購物比價、教學備課——只要是「查、比、寫、整理」的重複性工作，都能交給 Skills 代勞。

第二章 / 啟動 Gemini 側邊欄

開啟「問問 Gemini」

在開始使用 Skills 之前，先確認側邊欄已經正確啟用，並完成與 Google 服務的連結。

設定

基礎啟用

  • 更新 Chrome 至最新版本
  • 以 Win + R 快速開啟 Chrome
  • 點擊工具列的側邊欄圖示，開啟「問問 Gemini」
  • 發送一則測試訊息，確認功能正常回應
整合

服務串接

  • 在設定中開啟「AI 創新功能」
  • 連結 Google Workspace（文件、試算表、簡報）
  • 啟用 YouTube 影片內容理解
  • 啟用 Google 地圖資訊查詢

第三章 / Chrome Skills 安裝與啟用

從 Flags 頁面打開開關

Skills 目前是透過 Chrome 的實驗功能頁面啟用，步驟不多，但順序不能跳過。

🔒chrome://flags/#skills— 貼上網址列直接前往
  1. 進入 Flags 頁面
    於網址列輸入 chrome://flags/#skills 並按下 Enter。
  2. 啟用 Skills
    將對應項目的下拉選單從 Default 切換為 Enabled。
  3. 重新啟動 Chrome
    頁面下方會出現「Relaunch」按鈕，點擊以套用設定。
  4. 確認功能是否成功
    重啟後開啟側邊欄，若出現「Browse Skills」選項即代表啟用成功。

第六章 / 打造自己的 Skills

從使用者變成創作者

官方技能用完之後，下一步是把自己的工作習慣，做成專屬的 Skill。

Step 1

自訂 Prompt

把重複輸入的指令寫成固定範本，減少每次重新描述的時間。

Step 2

建立個人 Skills

將範本儲存為技能，之後一鍵呼叫即可使用。

Step 3

分享 Skills

把做好的技能分享給同事或社群，讓經驗可以被複製。

Step 4

管理 Skills

統一檢視、編輯、刪除已建立的技能，維持工作流程整潔。

第九章 / Q&A 與延伸學習

還想知道更多？

常見問題＋
初次使用時最常遇到的疑問，包含側邊欄無法開啟、Skills 選項未顯示等安裝相關問題，多半來自 Chrome 版本或 Flags 設定尚未完成。
技巧分享＋
把指令寫得具體、附上明確的輸出格式要求，能大幅提升 Skills 執行結果的可用性。
最新功能追蹤＋
Chrome Skills 仍在持續迭代，建議定期查看官方 Browse Skills 頁面掌握新增技能。
實作練習＋
建議從一項每週都會重複的工作開始，親手做出第一個屬於自己的 Skill。

完成導覽

換你打開側邊欄，
試試第一個 Skill。
