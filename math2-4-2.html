若 a ≥ 2，則下列哪一個不等式關係是正確的？
(A) 4 − a ≥ 2
(B) 2a + 1 ≥ 5
(C) a − 2 < 0
(D) 2(a + 3) ≥ 15
答案 (B)
a ≥ 2，兩邊乘 2 得 2a ≥ 4，再加 1 得 2a+1 ≥ 5（B 正確）。
(A) a ≥ 2 → −a ≤ −2 → 4−a ≤ 2，不等號方向錯。
(C) a ≥ 2 → a−2 ≥ 0，不成立。
(D) a ≥ 2 → a+3 ≥ 5 → 2(a+3) ≥ 10，不能確定 ≥ 15。
容易出錯
2
下列何者是一元一次不等式 3x + 2 > x − 4 之解的圖示？
（○ 為空心，● 為實心；解在 −3 右方為 B 型，左方為其他型）
(A) −3 空心，向左延伸
(B) −3 空心，向右延伸
(C) −3 實心，向左延伸
(D) −3 實心，向右延伸
答案 (B)
解：3x+2 > x−4 → 2x > −6 → x > −3。
x > −3：不含 −3（空心○），解在 −3 右方。選(B)。
容易出錯
3
滿足不等式 5x − 7 < 3x − 2 的最大整數為何？
(A) 3
(B) 2
(C) −3
(D) −2
答案 (B)
5x−7 < 3x−2 → 2x < 5 → x < 5/2 = 2.5。
小於 2.5 的最大整數為 2。

滿足不等式 5x − 15 ≤ −3x + 1 的正整數共有幾個？
(A) 2
(B) 3
(C) 4
(D) 5
答案 (A)
5x−15 ≤ −3x+1 → 8x ≤ 16 → x ≤ 2。
正整數且 ≤ 2：1、2，共 2 個。

美美帶著 150 元到文具店買每枝 12 元和每枝 20 元的原子筆若干枝。已知美美買的 12 元原子筆比 20 元的多 2 枝，則她最多可能買到幾枝 12 元的原子筆？
(A) 3
(B) 4
(C) 5
(D) 6
答案 (C)
設 12 元買 x 枝，則 20 元買 (x−2) 枝（x ≥ 2）。
總費用：12x + 20(x−2) ≤ 150
→ 12x + 20x − 40 ≤ 150 → 32x ≤ 190 → x ≤ 5.9375。
最多整數為 5 枝。

已知一個長方形的長是寬的 2 倍多 3 公分。若寬為 x 公分，且長方形周長不超過 42 公分，則依題意可列出不等式為                     。
答案 0 < 2(2x+3+x) ≤ 42
長 = 2x+3，寬 = x，周長 = 2×(長+寬) = 2(2x+3+x)。
「不超過42」且長方形有實際意義（x > 0），故列式 0 < 2(2x+3+x) ≤ 42。

若點 A(3x+6, 3x−5) 在第四象限，則 x 值的範圍為               。
答案 −2 < x < 5/3
第四象限：x 座標 > 0，y 座標 < 0。
3x+6 > 0 → x > −2；3x−5 < 0 → x < 5/3。
聯立得 −2 < x < 5/3。

已知一個三角形的底為 (2x−5) 公分，高為 6 公分，且面積不超過 18 平方公分，則：
(1) 依題意可列出不等式為                     
(2) 承(1)，x 的值至多為       
答案 (1) 0 < 6(2x−5)/2 ≤ 18　(2) x 至多為 11/2
面積 = 底×高÷2 = 6(2x−5)/2。底須為正：2x−5 > 0 → x > 5/2。
面積 ≤ 18：6(2x−5)/2 ≤ 18 → 3(2x−5) ≤ 18 → 6x−15 ≤ 18 → 6x ≤ 33 → x ≤ 11/2。
故 x 至多為 11/2。

祐丞目前的存款有 900 元。若從今天起每週存 500 元，則至少存      週後，祐丞就能買到價值 5700 元的手機。
答案 10 週
設存 x 週後：900 + 500x ≥ 5700 → 500x ≥ 4800 → x ≥ 9.6。
最小整數為 10 週。
