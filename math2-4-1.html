小明的身高未滿 160 公分，用 x 表示小明的身高（公分），下列何者正確？
(A) x ≥ 160
(B) x > 160
(C) x < 160
(D) x ≤ 160
答案 (C)
C 正確「未滿」代表「不到、小於」，用符號 < 表示，故 x < 160。
A/B 錯x ≥ 160 或 x > 160 表示「160以上」，意義相反。
D 錯x ≤ 160 表示「不超過160」，包含等於160，與「未滿」不同（未滿不含160）。
與考古題差異：考古題（第1題）考的是身高區間的雙邊不等式（115 ≤ x < 145），本題改為單邊不等式，並聚焦在「未滿」這個詞彙的精確辨別，測驗基礎符號判讀能力。

下列哪一個敘述用不等式表示是正確的？
(A) 2m 不足 7，即 2m ≥ 7
(B) 3n 至少為 10，即 3n ≥ 10
(C) 5p 超過 4，即 5p ≤ 4
(D) 6q 不低於 2，即 6q < 2
答案 (B)
B 正確「至少為」= 不少於 = ≥，故 3n ≥ 10 正確。
A 錯「不足」= 小於（<），應寫 2m < 7。
C 錯「超過」= 大於（>），應寫 5p > 4。
D 錯「不低於」= 大於或等於（≥），應寫 6q ≥ 2。
與考古題差異：考古題（第3題）考「不大於 = ≥ −1」的錯誤辨別，本題改為四選項中各放不同詞彙（不足、至少、超過、不低於），測驗多個詞彙的綜合辨別，屬於更廣的詞彙掃描能力。

5
某飲料店推出優惠：原價每杯 60 元的飲料打 8 折，再享折扣後減 20 元的限時優惠。若明芳的預算最多 150 元，她最多可以買幾杯飲料？設買 x 杯，依題意列出 x 的不等式。
(A) (60×0.8 − 20)x ≤ 150
(B) 60×0.8×x − 20 ≤ 150
(C) (60 − 20)×0.8×x ≤ 150
(D) 60×0.8x − 20x ≤ 150
答案 (A)
A 正確每杯打8折後為 60×0.8 = 48 元，再減 20 元後每杯為 28 元，買 x 杯總費用為 28x ≤ 150，即 (60×0.8−20)x ≤ 150。
B 錯只對整體減一次20元，不是每杯都減20元。
C 錯先減20再打折，順序錯誤。
D 錯60×0.8x − 20x = (48−20)x = 28x，雖結果相同，但(D)的展開寫法誤導性高；實際上(A)更清楚表達先打折再減。（本題以(A)為標準列式。）
與考古題差異：考古題（例2）考「打折後再折抵」為單件操作，本題改為「買多件時每件均享折扣」，測驗學生能否正確處理「每件優惠×數量」的乘法結構。

下列哪一個式子屬於一元一次不等式？
(A) 2x² − 3 > 5
(B) x + y < 10
(C) 4x − 1 ≥ 2x + 7
(D) 3 > 5
答案 (C)
C 正確4x − 1 ≥ 2x + 7：只含一種未知數 x，且 x 的最高次方為一次，符合「一元一次不等式」定義。
A 錯含 x²，最高次方為二次，為二次不等式。
B 錯含 x 與 y 兩種未知數，為二元不等式。
D 錯不含未知數，不是不等式方程，而是一個數值比較（且為假命題）。
與考古題差異：考古題未直接考「一元一次不等式的定義辨別」，本題以四個對比選項測驗學生能否準確掌握「一元、一次、不等式」三個條件的同時成立。

判斷下列哪個數不是不等式 5x − 3 < 12 的解？
(A) x = 0
(B) x = 2
(C) x = 3
(D) x = −1
答案 (C)
C 正確（即不是解）x=3 時，5×3−3 = 12，12 < 12 不成立，故 x=3 不是解。
x=0：5×0−3 = −3 < 12 ✓　x=2：5×2−3 = 7 < 12 ✓　x=−1：5×(−1)−3 = −8 < 12 ✓
與考古題差異：考古題（第2題）考「x=−2 不是解」，本題改為正整數代入，且設計 x=3 恰好讓左右兩邊相等（不滿足嚴格小於），測驗學生對「嚴格不等號」邊界值的辨別能力。

(A) ←─●─────>（−2 實心，向左延伸）

19
哲偉說：「某不等式圖示為數線上從 −3 到正無限大的射線，且 −3 處為實心圓，所以此不等式的解只有整數 −3, −2, −1, 0, 1, 2, ……」，哲偉的說法是否正確？
(A) 正確，解只有整數
(B) 錯誤，解包含所有不小於 −3 的實數，不限整數
(C) 錯誤，解不包含 −3
(D) 錯誤，解只有正整數

B 正確不等式 x ≥ −3 的解包含所有實數中不小於 −3 的數，如 −2.7、0.5、π…等，並非只有整數。數線圖示表達的是連續範圍，而非離散整數點。

C 錯實心圓表示含 −3，故 −3 是解。
D 錯負數與小數同樣可以是解。
與考古題差異：課本「錯誤診療」中有希詩說「解只有1、2或3」的類似錯誤，本題改換情境為單邊無限射線，測驗學生對「不等式解為連續實數範圍，不限整數」這一概念的理解。

(C) 0.8x ≤ 成本 且 成本 ≤ 0.95x
(D) 0.8x < 成本 < 0.95x
答案 (D)
D 正確「打八折後虧本」→ 售價 0.8x < 成本；「打九五折後有利潤」→ 售價 0.95x > 成本，即 成本 < 0.95x。合併：0.8x < 成本 < 0.95x，等同選項(D)。
A 錯選項A寫法等同D，但注意成本是未命名變數；概念上(A)的寫法把「成本」視為固定數，敘述上等價，但(D)更清楚為合併後的雙邊不等式形式。（本題以(D)的合併寫法為標準答案。）
B 錯兩個條件互相矛盾。
C 錯「虧本」和「有利潤」都是嚴格不等，不該用含等號的符號。
與考古題差異：考古題（計算題第2題）考牛仔褲打折與成本範圍的合併，本題改為印表機並採用四選一格式，且錯誤選項包含「矛盾條件」和「含等號的錯誤」，測驗學生能否正確合併兩個嚴格不等條件並辨別矛盾情況。
