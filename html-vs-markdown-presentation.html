— 歷史背景
為什麼過去
大家用 Markdown？
早期 LLM 的 context window 只有幾 K token，開發者必須節省每個字元。 Markdown 語法簡潔，而 HTML 標籤消耗大量 token，在小 context 時代不划算。

— HTML 的優勢
四大核心優勢
01
資訊密度
可嵌入 SVG 圖表、互動表格、錨點導覽，讓複雜資訊一頁呈現，而非線性文字堆砌
02
視覺豐富度
CSS 排版 + base64 內嵌圖片 + 空間佈局，視覺設計遠超 Markdown 的純文字限制
03
互動能力
JavaScript DOM 操作、可執行程式碼區塊、按鈕與篩選功能，Markdown 完全無法實現
04
分享便利性
單一 .html 檔案可在任何瀏覽器完整開啟，無需 Markdown 渲染器或特定閱讀器
— 全面對比
HTML vs Markdown
⬡ HTML
✦ SVG、Canvas、互動圖表
✦ CSS 自訂排版與樣式
✦ JavaScript 互動邏輯
✦ base64 內嵌圖片
✦ 長文件導覽錨點
✦ 豐富的跨平台渲染
✦ 可執行的程式碼沙盒
VS
⬡ Markdown
✦ 語法簡潔易讀易寫
✦ 任意文字編輯器可開啟
✦ Git diff 清晰可讀
✦ Token 消耗較少
✦ 版本控制友善
✦ 可直接轉換多種格式
✦ 適合資料處理管線
