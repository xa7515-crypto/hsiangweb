一、瀏覽器基本管理與帳號安全

對於需要頻繁切換不同帳號與身分的使用者（如教師、行政人員），基礎管理與安全設定是確保工作流暢與隱私保護的重要步驟。

1.1 系統更新

確保瀏覽器永遠保持最新是使用所有隱藏功能的基礎。

  • 位置： 右上角「⋯」> 說明 > 關於 Google Chrome。
  • 操作： 進入後系統會自動檢查並安裝更新，重新啟動瀏覽器以啟用新功能。

1.2 多帳號設定（Chrome Profiles）

適合擁有多個 Google 帳號（如學校、個人、AI 實驗與專用帳號）的使用者，避免帳號混淆與登入。

  • 管理： 點擊右上角頭像 > 管理 Chrome 設定檔（或個人資料）。
  • 新增與區分： 可為不同帳號設定獨立的主題與配色方案，並開啟「同步功能」以載入個人書籤。
  • 安全性建議： 在校園共用裝置使用時，建議至「管理 Chrome 設定檔」點擊特定設定檔旁的「刪除」，以確保瀏覽器密碼與自動填入資料不被竊取。

1.3 無痕視窗與來賓模式的差異

功能使用時機特點
無痕視窗（Ctrl + Shift + N） 暫時不想在個人帳號下留下瀏覽紀錄時 使用當前設定檔，但不儲存瀏覽紀錄、Cookie 與表單資料。
來賓模式 使用他人電腦或不特定電腦時 完全獨立，無法觸及電腦上其他使用者的瀏覽資源，離開時自動清除所有瀏覽痕跡。

二、瀏覽器自訂與高效能

透過自訂配置，使用者可以將瀏覽器塑造成符合個人視覺習慣與操作邏輯的工具。

2.1 自訂 Chrome（Customize Chrome）

在「新增分頁」右下角可進入自訂面板：

  • 外觀變換： 可切換預設主題或上傳個人背景圖。
  • 捷徑管理： 可選擇顯示「最常瀏覽網站」或關閉「自訂捷徑」。
  • 工具列功能強化： 可將常用功能（如智慧鏡頭、QR Code 產生器、閱讀模式）釘選至上方工具列。

2.2 核心快速鍵大全

善用快捷鍵可在日常教學與行政事務中大幅節省操作時間：

放大頁面Ctrl + +
縮小頁面Ctrl + -
回復 100% 原始大小Ctrl + 0
開啟新視窗Ctrl + N
關閉當前分頁Ctrl + W
回復最近關閉分頁（最多 25 個）Ctrl + Shift + T
新增書籤Ctrl + D
顯示／隱藏書籤列Ctrl + Shift + B
開啟表情符號／表情貼Windows + .

三、分頁管理與分頁群組

同時開啟大量分頁時，群組功能可有效降低視覺混亂並節省資源，優化記憶體占用。

3.1 分頁群組化操作

  • 建立群組： 在分頁上按右鍵 > 「將分頁加入新群組」。
  • 管理： 可為群組命名（如：AI 工具、工作常用、參考資料）並選擇顏色。
  • 折疊與展開： 點擊群組名稱即可收起節省空間。
  • 群組固定顯示： 在書籤列按右鍵，選擇「顯示分頁群組」，可將常用的群組釘選，即使重新開啟瀏覽器也可快速復原群組配置。

四、內建 AI 工具：Google 智慧鏡頭與 AI 功能

Chrome 內建的智慧鏡頭已將 OCR（光學字元辨識）與 AI 模型深度融合。

4.1 圖片文字辨識與翻譯

  • 操作： 在圖片上按右鍵 > 「透過 Google 智慧鏡頭搜尋」。
  • 文字處理： 可自動標記「可複製文字」或點擊「聆聽」讓系統朗讀以獲取圖片內文。

4.2 AI 功能：圖片搜尋與摘要

  • 自動化流程： 進入智慧鏡頭後，選擇「AI 功能」，可下達如「請將圖片中的英文翻譯成中文」。系統會自動分析圖片內容並生成結構化的文字結果，節省手動輸入與整理的時間。
  • 以圖搜圖： 透過智慧鏡頭框選圖片中特定區域（如建築物、電子產品），可即時搜尋網路上相關資訊與購物連結。

4.3 QR Code 快速產生

  • 產生： 在網址列右鍵 > 「為此頁面建立 QR 圖碼」，或從工具列圖示點入。
  • 應用： 可下載 QR Code 圖片或複製連結至剪貼簿，方便與他人分享網頁。

五、閱讀模式與實驗性功能

5.1 閱讀模式（Reading Mode）

解決網頁內容過長、版面混亂的痛點。

  • 開啟方式： 右上角 ⋯ > 以閱讀模式開啟。

核心功能

  • 沉浸文本： 自動清理雜訊，只保留核心內容。
  • 朗讀功能： 支援逐句中英文朗讀，可調整朗讀速度（如 2 倍速）並提供逐字 OK 確認的文字標示。
  • 閱讀設定： 可調整字體大小、字型、行距與字距。

5.2 實驗性功能：分割畫面（Split View）

讓使用者在同一個視窗內並排檢視兩個分頁，適合對照資料或一邊撰寫一邊參考 AI 生成結果。

  • 啟用方式： 進入 chrome://flags 找到 Chrome Labs，搜尋並啟用 Split View。
  • 操作： 在分頁上按右鍵 > 「將分頁加入分割畫面視窗」。
  • 應用場景： 左側放置原始文獻對照，右側檢視參考結果。
⚠️ 注意： Split View 為實驗性功能，穩定性和介面可能隨版本更新變化。
